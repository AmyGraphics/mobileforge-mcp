# MobileForge MCP Server 📱🚀🔔

Universal Autonomous Mobile App Architecture, React Native/Expo Screens, Offline Sync, Push Notifications & App Store Release Engine MCP Server for **Cursor, Claude Code, Windsurf, and Autonomous AI Agents**.

## 🌟 Core Capabilities:
- 👑 **Master 1-Shot Outcome Engine (`autonomous_mobile_app_architect`):** Ingests the app concept and team profile to synthesize a complete mobile blueprint in one call: framework decision matrix (Expo vs Flutter vs native vs PWA), Expo Router navigation tree, state management plan, offline-first strategy, monetization model, and an 8-week launch roadmap to both stores.
- 📱 **Production Screen Generator (`generate_react_native_screen`):** Typed Expo Router screens with SafeArea, skeleton loading, pull-to-refresh, empty states, dark mode, accessible labels, and FlashList for long lists.
- 🔄 **Offline Sync Engine (`implement_offline_sync_engine`):** expo-sqlite local source of truth, outbox mutation queue surviving restarts, optimistic UI, background flush with backoff, and conflict resolution with tombstone deletes.
- 🔔 **Push Notification Stack (`build_push_notifications`):** Expo permission flow, device token registration, FCM/APNs credentials checklist, deep linking per notification type, and server-side Expo Push API send code.
- 🏁 **App Store Release Kit (`prepare_app_store_release`):** EAS build profiles, app config, store listing metadata with keyword strategy, screenshot checklists, TestFlight/Play Console submission flow, and phased rollout with OTA hotfix strategy.
